# HR Analytics Dashboard

### 🎯 Project Objective
The goal of this project is to analyze HR employee data, understand why employees leave (attrition), and find key workforce trends to help the organization make better decisions.

### 🛠 How I Built This Project (Tools & Process)
* **Data Source:** I started with raw HR employee data in an Excel file.
* **Data Cleaning:** I loaded the data into Power BI and used **Power Query** to clean it up, fix missing values, and create new columns to make the data ready.
* **Calculations (DAX):** I wrote **DAX formulas** to create measures for key metrics like total attrition count and department percentages.
* **The Dashboard:** Finally, I designed an interactive dashboard with dynamic **Slicers and Filters** so anyone can easily filter data by department, job role, or age group.

### 📊 Key Insights & Features
* **Workforce Overview:** Shows KPI cards for Total Employees, Active Employees, and Attrition Rate.
* **Attrition Analysis:** Visualizes who is leaving based on Department, Age Groups, Gender, and Salary Slabs.
* **Interactive Charts:** Used clean charts (like Donut, Bar, and Funnel charts) and **interactive Slicers** to make the data easy to navigate at a glance.
